# 👨‍💻 Ruan Rodrigues

### AI Engineering | LLMs | RAG | AI Agents | Machine Learning

Computer Science student at the **Federal University of Campina Grande (UFCG)**, currently working in Research & Development at **LACINA**, contributing to AI projects in partnership with Dell Technologies.

My work focuses on building intelligent systems with Large Language Models (LLMs), designing AI agent architectures, developing Retrieval-Augmented Generation (RAG) pipelines, and evaluating model and agent performance.

### 🤖 AI & Machine Learning

- **AI Agents & Orchestration:** Building agent-based architectures and conversational workflows with LangGraph and LangChain.
- **Prompt Engineering:** Designing and improving prompts and agent workflows to enhance response quality, consistency, and relevance.
- **RAG Systems:** Exploring advanced retrieval techniques, including HyDE, to improve information retrieval and response quality.
- **Model & Agent Evaluation:** Developing evaluations and benchmarks to analyze performance, identify limitations, and guide improvements.
- **Multi-Agent Systems:** Working on autonomous systems for codebase analysis and software security vulnerability identification.
- **Machine Learning:** Developing applied ML projects, including audio classification using feature extraction and neural networks.
